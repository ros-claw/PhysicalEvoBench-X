# 开发任务分布校准 v1

执行前设计，2026-10-26。独立任务修订 `DEVELOPMENT_GEOMETRY_MATERIAL_V1`，全部为公开开发输入，`formal_result_eligible=false`。不修改冻结 v0.1 的工厂、控制器、配置或评分，不将候选评分设为默认。

目的：检查新的物体条件是否产生可测、可重复的宏观技能差异，以及现有五维技能是否有学习空间。不会以正迁移、接受更新或特定成功率作为验收条件。无 LLM、无学习、无正式 test 数据；完整保留零差、负差、失败与安全停止。

| 条件 | 尺寸 m | 质量 kg | 物体静/动摩擦 |
|---|---|---|---|
| nominal | .045 × .045 × .065 | .20 | 1.0 / 1.0 |
| tall_narrow | .035 × .035 × .140 | .20 | 1.0 / 1.0 |
| wide | .065 × .065 × .065 | .20 | .5 / .5 |
| heavy_low_friction | .045 × .045 × .065 | .65 | .2 / .2 |

后两项是联合压力条件；本批不能分离宽度/摩擦、质量/摩擦的因果效果。物体材料读回不等于组合后的接触摩擦。所有位置固定 x=.5、y=0、初始底面距桌面 .002 m，yaw=0，reset seed=2026102603；两夹爪共享条件。新几何通过评测端在 builder 前完整替换对象及其 reset 事件，并同步可信观测尺寸；模型没有修改场景的权限。

三种预声明配置：原 `SkillSpec.initial()`；仅抓取高度 .50→.70；仅抬升速度 .10→.03 m/s、加速度 .30→.10 m/s²。其他参数、准备动作（.5 s 零相对动作）、控制器、驱动与 64/4 求解器均保持原值。慢抬升是联合轨迹干预，不归因到单一速度或加速度字段。

两个本体各四条件×三技能=12 次，加上细高条件三种技能各一次完全相同的独立场景重复，共 **30 次**。技能顺序随条件轮换；重复安排在末尾。所有调用重新创建物理场景，不缓存成绩、不把重复算作免费调用。

技能动作前核验 PhysX 质量、惯性、物体材料，USD 相对物体根节点的几何尺寸、reset 位置和求解器作用域。读回不一致即停止该 worker，保留 STARTED 日志，不静默重试。采集完整 15 秒任务时段的 50 Hz 控制及 200 Hz 物理状态；实测约束触发时允许提前安全停止。并行记录候选两频率和旧评分，离线重算三者。任务成功不等于执行有效；评分分歧单列。细高重复逐项比较公开观测（除 episode_id）与实际动作，不以单次差异宣称可重复性。

验收依次为：场景读回真实一致；日志/成本/覆盖无缺失；全部评分可从留存轨迹重算；重复性结果明确；报告完整三技能比较及候选与旧评分差异。即使未发现技能差异也完成并如实报告，不据此自动扩展参数搜索或冻结正式新分布。
