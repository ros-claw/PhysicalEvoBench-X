## 第二优先：只在独立开发条件上诊断

本次测试数据可用于如实解释已有结果，但不得据此修改当前版本、重新选择产物或再报告同一测试集上的调参收益。新的控制实验使用独立开发条件，并单独记账：

1. 用冻结初值和两个已接受产物，检查每个参数对接近时序、抬升参考、实际跟踪、相对滑移和稳定保持的影响，定位 Kimi 负迁移的可复现机理。
2. 检查初始控制器高成功率、探索条件数量和验证门槛分别怎样限制更新与可观测效果。区分没有更新、源更新未泛化、更新迁移失效、目标适配未恢复四种情况。
3. 设置已知技能差异的灵敏度对照与完全等价的零差对照，验证测量能识别不同表现及其方向。这些属于测量验证，不能冒充学习产生的迁移。

## 第三优先：预注册 v0.2

根据开发诊断，确定具有足够难度跨度的任务分布、固定初值、必要的技能表示和主要指标；保留合理且相同的公共控制底座。目标是让成功、失败、正迁移与负迁移都有测量空间，不要求某方法获得正结果。

冻结新的代码、开发与测试分离规则、条件分布和接受规则。依据 pilot 的独立 run 差异与预先声明的最小关注效应，确定更多独立学习重复及预算。若研究主张涉及物理反馈或经验表示的贡献，应预先加入同模型/推理预算的无反馈对照或表示对照；不由单纯的 Kimi 与 Random 比较推断这些机制。

首轮继续围绕两个已标定的末端配置验证新测量设计，再决定是否扩展到不同机械臂、条件技能和多轮继承。所有新诊断、新版本结果与 v0.1 归档分开。
