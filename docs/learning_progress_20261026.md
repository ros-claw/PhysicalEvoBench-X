# 真实源学习与零预算迁移：2026-10-26

本轮完成 108 次真实 Arena/PhysX 调用，得到一个有限的源学习后迁移改善实例。原定 Random、Kimi 均没有产生被接受的更新；随后追加的单参数高度覆盖方法在新的独立条件上产生更新。后者属于事后选择的开发诊断，不能据此给三种方法排名，也不能宣布正式 benchmark 已证明普遍正迁移。

| 方法 | 源验证 Before→候选 | 独立源审计 Before→After | Robotiq 目标 Before→After | 更新 |
|---|---|---|---|---|
| Random | 2/4→2/4 | 2/4→2/4 | 0/4→0/4 | 回滚 |
| Kimi k3 | 2/4→2/4 | 2/4→2/4 | 0/4→0/4 | 保留初值 |
| 高度覆盖（新条件，事后选择） | 2/4→4/4 | 2/4→4/4 | 0/4→2/4 | 接受 |

每种方法仅一个源学习 seed，Panda→Robotiq 一个方向。每包 20 次源练习、8 次独立源审计、8 次目标评测，合计 60/24/24 次；目标追加练习为 0。回滚后的 Before/After 也分别真实执行，没有用别名替代物理调用。原两包的 16 个同产物配对全时段公开状态与实际动作精确一致。

高度覆盖在已有边界内评估初值 0.5 与五个固定候选 0.45、0.525、0.6、0.675、0.75，其余四参数固定初值。源训练反馈选出 0.75，按原验证接受规则接受。源技能在目标评测开始前已公开冻结于提交 `a7cf765`；最终产物哈希与当时记录一致。它在两个高窄目标条件由失败变成功，两个宽条件仍失败，没有观察到退化。它检验的是可选择的单参数经验迁移，不是 LLM 获胜或条件技能学习。

完整留存轨迹的三套评分共重算 324 次，与在线记录全部一致；本批 50/200 Hz 成功分类分歧为 0。源学习通过只读缓存重建，并检查模型请求只包含源练习历史。Kimi 实际请求 5 次，5 个合法输出、0 个错误，provider usage 8,197 tokens；响应模型为 k3，未获得不可变模型版本。

准备时段检查每包 17/22 对全字段精确一致，其余差异标志原样保留：Random/Kimi 的最大差仅为关节速度约 3.45e-8 rad/s；高度覆盖还出现最大约 1.20e-6 rad/s 关节速度、1.15e-7 m TCP 位置及 1.73e-7 四元数分量差异。没有事后改容差或把这些标为精确相等；独立源审计与目标配对准备状态一致。数值差异详见各包报告。

累计观察仿真时间 1,674 秒，累计回合壁钟 10,668.41 秒（建场景至结果捕获，不含 teardown，含并行包累加；模型耗时另列）。成功后仍观察完整任务时段，不能从首次成功时间推断已节省仿真成本。两个 Python 环境各 142 项测试通过；旧校准与物理敏感性计划的冻结输入校验仍通过。没有为报告修复重新执行物理调用。公开导出已检查实际密钥缺失与私有精确场景排除，图表逐张复核；原始报告/图形排版尝试保留。

这些证据支持开发闭环能够记录失败、选择源产物并观察目标差异。其适用范围仍是同机仿真、已知几何方块、窄分布、一个方向与每方法一个学习 seed、每目标仅四个配对条件。没有无反馈消融、反向多 seed 验证、总体显著性、真实机器人或通用 VLA 结论；原始大轨迹保留本机，因此公开摘要一致性也不等于独立机器物理复现。候选 50 Hz 判据仅用于明确版本化的新开发任务，旧默认判据、旧结果和冻结源码未改，尚未发布新正式 benchmark。
