## 仍然限制结论的因素

1. **任务上限效应明显。** 初始控制器接近满分，成功率难以区分方法。可按原协议报告完成时间等辅助指标，但不能事后换主指标来宣称正迁移。
2. **源端接受不等于源泛化，更不等于目标迁移。** Robotiq 的 2/4→4/4 是接受决策；必须完成独立源审计，再检验目标 Before/After。
3. **范围很窄。** 同一 Franka 机械臂、两套末端配置、固定状态机、已知几何与状态。五个标量不代表自由技能学习；配置还包含自碰撞、驱动和底座差异，不能仅归因于夹爪硬件，更不能推广到任意机器人或真机。
4. **三个 seed 是 pilot。** 50 个测试条件不是 50 次独立学习。应展示每个完整 run 的配对差、回滚率和成本，不用测试回合数制造学习层面的强显著性。
5. **模型服务存在随机性与版本限制。** K3 没有固定权重版本或可验证的服务端 seed。探针成功不代表整个 LLM 学习矩阵已验证，LLM 与随机搜索的对比也不足以单独归因于物理反馈的价值。
6. **针对可信内部实验。** 哈希与接口约束不构成对恶意参赛系统的完整安全隔离。

可信 benchmark 可以得到正、零或负结果。正迁移未证实不自动否定测量协议；但全矩阵、独立复现、测量灵敏度和统计报告尚缺，因而也不能称首版 benchmark 已完成验收。
